Question 2 Explanation
======================

ไฟล์ source code:
q2_maxflow.c

ไฟล์ input ตัวอย่าง:
input/q2_sample_input.txt

ไฟล์ output ที่ได้:
output/q2_output.txt

แนวคิดของโปรแกรม:
โปรแกรมอ่านจำนวนโหนด N จากบรรทัดแรก โดยกำหนดให้ node 0 เป็น source
และ node N - 1 เป็น sink จากนั้นอ่าน edge ในรูปแบบ triplet:

i j capacity

โปรแกรมสร้าง adjacency list จำนวน N head entries ตามที่โจทย์กำหนด
เมื่อเพิ่ม edge u -> v จะเพิ่ม reverse edge v -> u capacity 0 ด้วย
เพื่อใช้เป็น residual network ระหว่างการหา augmenting path

อัลกอริทึมที่ใช้:
Ford-Fulkerson method โดยเลือก augmenting path ด้วย Breadth First Search (BFS)
วิธีนี้มักเรียกว่า Edmonds-Karp algorithm

ขั้นตอนหลัก:
1. ใช้ BFS หา path จาก source ไป sink ที่ยังมี residual capacity เหลือ
2. หา bottleneck capacity ของ path นั้น
3. เพิ่ม flow บน forward edge และลด flow บน reverse edge
4. ทำซ้ำจน BFS หา path จาก source ไป sink ไม่เจอ
5. พิมพ์ max flow และ flow/capacity ของ original edge ทุกเส้น

สำหรับกราฟตัวอย่างในโจทย์:
Maximum flow from 0 to 5 = 19

flow ที่ assign ให้แต่ละ edge:
0 -> 1 : flow 10 / capacity 10
0 -> 2 : flow 9 / capacity 10
1 -> 2 : flow 0 / capacity 2
1 -> 3 : flow 4 / capacity 4
1 -> 4 : flow 6 / capacity 8
2 -> 4 : flow 9 / capacity 9
4 -> 3 : flow 5 / capacity 6
3 -> 5 : flow 9 / capacity 10
4 -> 5 : flow 10 / capacity 10

คำตอบข้อ 2:
Max flow value = 19

gcc q2_maxflow.c -o q2.exe
