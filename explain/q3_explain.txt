Question 3 Explanation
======================

สำคัญ:
จากรูปและ PDF ที่ให้มา โจทย์ข้อ 3 อ้างถึง
"Bike sharing in-class assignment 6-2"
แต่ไม่ได้ให้ตัวเลขกราฟ Bike sharing นั้นมาในไฟล์นี้
ดังนั้นยังไม่สามารถคำนวณคำตอบตัวเลขจริงของข้อ 3 ได้จากข้อมูลที่แนบมา

ไฟล์ source code สำหรับข้อ 3:
q3_bike_sharing.c

ไฟล์ template input:
input/q3_bike_template_input.txt

ไฟล์ template output:
output/q3_template_output.txt

รูปแบบ input ของข้อ 3:
บรรทัดที่ 1: N
บรรทัดที่ 2: E
จากนั้น E บรรทัดเป็น:
u v capacity

หลังจากนั้นใส่จำนวน location ที่มี reservation demand:
D

แล้วตามด้วย D บรรทัด:
node demand

ตัวอย่าง:
6
9

0 2 10

คำอธิบายการตอบข้อ 3(a):
ให้นำกราฟจริงจาก Bike sharing in-class assignment 6-2
มาใส่ใน input/q3_bike_template_input.txt
แล้วรันโปรแกรม:

gcc q3_bike_sharing.c -o q3.exe
.\q3.exe input\q3_bike_template_input.txt

ค่าที่ต้องตอบคือ max flow value
ซึ่งแทนจำนวน bikes สูงสุดที่สามารถ transported among locations ได้
ส่วนการวาด flow network solution ให้ใช้ flow/capacity ที่โปรแกรมพิมพ์ออกมา
ไปเขียนกำกับบน edge แต่ละเส้น

คำอธิบายการตอบข้อ 3(b):
ดูบรรทัด "Reservation check by location"
ถ้า location ทุกตัวมี received >= demand แปลว่า reservations satisfied at every location
ถ้ามี location ใด received < demand แปลว่าไม่ satisfied

ผลจาก template input ปัจจุบัน:
Bike sharing max flow = 19
Total customer reservations = 19
location 3: received 9, demand 10, not satisfied
location 4: received 15, demand 9, satisfied

ดังนั้นสำหรับ template input นี้:
Are the customer reservations satisfied at every location?
No, because location 3 receives only 9 bikes but has demand 10.

หมายเหตุ:
ผลนี้เป็นคำตอบของ template input เท่านั้น
ยังไม่ใช่คำตอบสุดท้ายของ Bike sharing assignment 6-2
จนกว่าจะใส่กราฟและ reservation demand จริงจาก assignment นั้น
